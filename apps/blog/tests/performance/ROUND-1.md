# 1차 측정: Tailwind 유틸리티 전환과 폴더 정리

2026-09-13에 원본 `7c4fa58e`의 프로덕션 빌드와 최종 작업 트리를 비교했다. StyleX 전환, 미사용 스타일 제거, 컴포넌트/스타일 파일 분리, 클래스·CSS 변수 이름 정리를 모두 포함한 결과다. StyleX 라이브러리만의 효과를 분리한 실험은 아니다.

**이 환경에서는 LCP가 소폭 짧아졌지만, 전체 전송량이나 메인 스레드 작업 시간이 감소하지는 않았다.** CPU 관련 수치는 실행 간 범위가 겹치므로 작은 중앙값 차이만으로 성능 저하를 단정하지 않는다.

- Node 24.20.0, pnpm 12.1.0, Next.js 16.3.1. Tailwind 4.3.3과 StyleX 0.19.0을 비교했다.
- 모바일 390 × 844, DPR 2, 터치, 라이트 모드. 애니메이션과 캔버스는 정상 실행했다.
- CPU 20× 감속, 다운로드·업로드 400 Kbps, 최소 네트워크 지연 400 ms.
- 두 경로 × 두 버전 × 5회 = 20회. 매번 새 브라우저, HTTP 캐시 비활성화/초기화, 서비스 워커 우회. 서버 데이터와 이미지 캐시는 사전 방문으로 준비했다.
- AB/BA 순서를 번갈아 실행했다. 로드·폰트 준비·network idle 이후 5초까지 관찰했다. 실패한 실행이나 느린 실행을 골라 제외하지 않았다.
- GA/Tag Manager는 양쪽에서 차단했다. 기존 jsDelivr KaTeX 0.13.0 CSS는 양쪽 모두 실제로 요청했으므로 CDN 응답 변동이 포함된다.
- 빌드와 시각 비교 작업이 끝난 뒤 측정했다. 스로틀링은 이 호스트의 상대적 감속이며 실제 휴대폰 속도나 운영 서버 응답 시간을 재현하는 수치는 아니다.

측정 시각: `2026-09-13T08:30:58.410Z` ~ `2026-09-13T08:41:14.235Z` (UTC).

원본은 별도 worktree에서 빌드했다. 설치된 의존성을 링크해 사용했고, 공유 패키지는 원본 worktree의 코드를 가리키도록 분리했다. 이 링크를 빌드 범위에 포함하기 위해 원본의 `turbopack.root`만 `/Users/yceffort/private`로 지정했다. 원본 UI 코드는 변경하지 않았다.

## 해석과 한계

- LCP 중앙값은 홈 5,748 → 5,572 ms(−3.06%), 글 상세 8,640 → 8,480 ms(−1.85%)였다. 각각의 전후 측정 범위는 겹치지 않았고, 5쌍 모두 StyleX 쪽 값이 낮았다. 다만 두 경로와 한 기기의 로컬 실험 결과다.
- LCP 대상은 모든 홈 실행에서 같은 첫 글 썸네일(70,844 px²), 글 상세에서는 같은 H1(34,238 px²)이었다.
- CSS 전송은 약 6.8% 줄었고, JS 전송은 홈 3,671 bytes / 글 상세 5,090 bytes 늘었다. 전체 전송은 각각 약 0.31% / 0.61% 증가했다. 두 경로 모두 요청은 1개 늘었으며, 홈에서는 JS 요청이 12 → 13개로 늘었다. CSS 파일 총량 감소가 전체 다운로드 감소를 뜻하지는 않는다.
- 메인 스레드 누적 작업 중앙값은 두 경로에서 약 2.6% 증가했다. 특히 글 상세의 StyleX 실행 범위가 11.23–15.05초로 넓었으므로, 작은 중앙값 차이를 확정적인 CPU 회귀로 해석하지 않는다. 관찰 구간 길이와 정상 실행 중인 애니메이션의 작업도 포함된다.
- CLS 중앙값은 홈 약 0.0025, 글 상세 0으로 동일했다. `loadBlockingMs`는 관찰 구간의 long task에서 50 ms를 초과한 시간이며 Lighthouse TBT가 아니다. INP는 측정하지 않았다.
- 보조 컴파일 검사에서는 `AnnouncementBanner`의 StyleX 선언을 같은 파일에 두었을 때 남지 않던 `stylex.props` 호출이, 별도 스타일 파일로 옮기면 15개 남는 것을 확인했다. 최종 클라이언트 청크에도 클래스 조합 호출이 남아 있다. 정적 변환 범위가 줄어드는 비용이 있다는 증거이며, JS 증가량 전부를 이 요인으로 분리 측정한 것은 아니다.
- 스크린샷 일치 검사는 별도 실행했다. 이번 성능 기록에는 애니메이션 정지, 캔버스 마스킹, 태그 합성 설정 변경을 적용하지 않았다.
