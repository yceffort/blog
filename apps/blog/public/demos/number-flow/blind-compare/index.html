글꼴 하나의 차이

숫자 폭이 달라지면?

배경 갱신을 끄고 9자리 숫자 하나만 바꿨다. 글꼴 조건을 바꿔 별도로 잰 결과를 비교해 보자.

    회/s, 막대 눈금은 두 조건 모두 0~60

    2026년 11월 2일, Chromium 151, CPU 4배 감속에서 잰 3회 평균이다. 실시간 측정값이 아니다. 갱신 태스크와 JavaScript 실행 밖의 재계산을 세어 시작과 종료 주변의 처리도 포함했다. 횟수가 같아도 실제로 쓴 시간은 다를 수 있다.

    같은 입력, 7개 빌드

    다 굴러가기 전에 새 값이 오면?

    인터럽트 연타는 250ms 간격으로 값을 바꾼다. 느리게 보기를 켜서 이전 움직임이 어떻게 이어지는지 살펴보자.

    각 빌드에 같은 값을 보낸다. 메시지를 받는 시점에는 차이가 있어 움직임이 정확히 같은지 재는 도구는 아니다.

    재생 방식과 조작 안내

    느리게 보기는 애니메이션과 갱신 간격을 함께 3배로 늘린다. 숫자 폭 고정은 monospace 글꼴로 바꾼다. 멈추기는 각 빌드의 애니메이션과 JavaScript 프레임 진행을 함께 멈춘다. 시스템에서 동작 줄이기를 켰다면 number-flow가 애니메이션을 끈다.

    빌드 파일은 재측정에 쓴 번들(esbuild 0.28.2, es2019) 그대로이고, 업스트림 number-flow(MIT, Maxwell Barvian)의 파생물이다. 라이선스
